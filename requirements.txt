# Main environment: the complete package set of the reference environment (Python 3.12.14, pip; CUDA 13.0 build of
# torch from PyPI). Every reference run of the campaign was trained and evaluated with exactly these versions.
#
#   conda create -n dvd python=3.12.14 -y && conda activate dvd        # any Python 3.12 works; 3.12.14 is the reference
#   pip install --no-deps -r requirements.txt
#
# --no-deps is required, not a shortcut: the list is complete (it is a freeze), and it cannot be resolved, because
# lerobot 0.6.2 declares numpy<2.3 while the reference environment runs it with numpy 2.3.5. Without --no-deps pip
# stops with ResolutionImpossible. `pip check` afterwards reports that one conflict and nothing else.
#
# robosuite is the only line that is not in the reference freeze: there the unpacked 1.4.1 wheel sits on PYTHONPATH
# (scripts/env.sh: ROBOSUITE_ROOT) with one line patched for numpy 2 (environment.md, "robosuite"). MimicGen,
# robosuite-task-zoo, the DSRL stable-baselines3 fork and RoboMeter are source checkouts, not pip packages
# (environment.md, "Third-party checkouts"). System packages: ffmpeg 6.x (torchcodec decodes with it), NVIDIA EGL.
